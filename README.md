# LPS-Advicacia

Site institucional one-page do **LPS Advocacia** — escritório de advocacia em Santiago/RS.
Estética premium, minimalista e editorial: azul marinho, off-white, detalhes em dourado champagne e tipografia serifada nos títulos.

## Estrutura

```
index.html    # página única (header, hero, sobre, áreas, método, equipe, atendimento, localização, CTA, footer)
styles.css    # design system, layout editorial e responsivo
script.js     # header ao rolar, menu mobile, animações de entrada, menu ativo
equipe.jpg    # fotografia dos gestores (exibida apenas na seção Equipe)
robots.txt    # instruções de indexação
```

## Como visualizar

Basta abrir `index.html` no navegador, ou servir a pasta localmente:

```bash
npx serve .
```

## Antes de publicar

- Trocar o link do Instagram no footer pelo perfil oficial.
- Completar o campo de OAB / informações institucionais.
- Opcionalmente substituir o mapa minimalista (SVG) pelo Google Maps embutido.
